# G2Cashify v1.0.0

First release of the G2Cashify business website.

- Responsive desktop and mobile layouts for iPhones, laptops, storage drives, and selected Android phones.
- Facebook branding, logo, app icon, and Facebook page links.
- Device quote preparation, photo previews, and customer-controlled Messenger handoff.
- Installable PWA with offline fallback.
- Cloudflare Worker deployment at https://g2cashify.com.
- GitHub Actions workflow to deploy the released tag when a GitHub release is published. Requires the repository's CLOUDFLARE_API_TOKEN secret.

Validation: JavaScript syntax checks and Messenger handoff regression checks.
