# G2Cashify

Responsive, dependency-free business PWA. Run `npm start` to preview at http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax validation.

The quote form validates device/contact information, previews up to four images, and creates a downloadable text request. It does not send requests or upload photos. Connect an actual submission service and replace the contact, social, service-area and hours placeholders before accepting customer enquiries. No personal data is persisted automatically.

PWA installation requires HTTPS (or localhost) and browser support. The site shell and offline fallback are cached after the first successful online visit. Font loading is optional; local font fallbacks work offline.
